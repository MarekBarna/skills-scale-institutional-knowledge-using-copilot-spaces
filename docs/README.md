# OctoAcme Project Management Docs

This README provides a single entry point to the OctoAcme project management process documents and summarizes the operating model used by the team.

## Project management process overview

OctoAcme follows a lightweight, repeatable project lifecycle designed to move ideas from validation to delivery and improvement:

- Initiation: confirm the business problem, stakeholders, success metrics, and go/no-go decision for planning
- Planning: define scope, backlog priorities, milestones, dependencies, and the definition of done
- Execution: deliver in small increments, track progress on the project board, and manage blockers through standups and reviews
- Release & deployment: confirm readiness, run smoke tests, deploy with rollback planning, and communicate the release outcome
- Risk & communication: maintain a risk register, escalate issues appropriately, and keep stakeholders informed with regular updates
- Retrospective & improvement: capture learnings, assign action items, and improve the process over time
- Roles & responsibilities: define ownership for product, project, engineering, testing, and stakeholder coordination
